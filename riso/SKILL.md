# Riso 孔版印刷 —— 一种颜色一张版，一版一版印出来

不是滤镜，不是生图。每个颜色是一张「版」（浓度图 0..1），画的时候只往版上涂浓度；印的时候：浓度 → 网点/颗粒 → 墨不匀、白点、滚筒条纹 → 整版偏一点、转一点 → 半透明油墨乘法叠印到纸上。
**颜色是印出来的，不是调出来的**：粉叠黄得红，蓝叠黄得绿，蓝叠粉得紫，三色全叠得近黑。

依赖：`pip install pillow numpy scipy`。一张 600×840 两三秒，900×1200 五到八秒（内部 2 倍超采样）。

第一次用先跑 `python3 example.py`：出来的 `example.png` 和包里的一模一样（seed 固定），环境就对了。跑不出来只有两种原因：没装 pillow / numpy / scipy；中文变方块是缺中文字体（引擎会自动找 Noto CJK → 苹方 → 冬青黑，都没有就装 Noto CJK，或者改 `R.FONT_BOLD` / `R.FONT_REG`）。

## 最重要的一条：设计比质感重要

Riso 好不好看，九成在「用哪几块颜色、怎么摆」，颗粒和错位只是最后那层皮。先把设计做对，再上质感；质感救不了设计。

1. **满版底色本身就是一张版。** 整张铺一种颜色（蓝、粉、红、黄、藏青），白色的东西都是「挖掉」露出来的纸。大半张空纸 = 插画，不是印刷品。
2. **少色、敢用。** 三色以内。选一个底色 + 两个点缀色。荧光粉几乎和什么都配；金色配蓝配粉特别好看。
3. **大剪影，没有轮廓线。** 圆滚滚的几何形，靠色块交界分形状。不要描边。
4. **细节靠留白点出来。** 白圆眼睛 + 深色瞳孔、白点、星星、条纹，都是在版上挖出来的纸色。
5. **要有一个点子。** 像那种「猫藏在仙人掌/蛋糕/达摩里」的小卡：同一个角色反复出现在不同东西里，比画工重要得多。动笔前先用一句话写下点子，没有点子不动手。
6. **Riso 印不到纸边。** 四周留白边（600 宽留 26，900 宽留 34）。让东西从框里「溢出去」到白边上，是很可爱的破格。

## 分版思维（写代码时脑子里只有这三个动作）

- `solid(pts, plate)`：这块只印一个颜色 → 其他版在这里挖掉，这版涂满。
- `knock(pts)`：这块是纸 → 所有版都挖掉。
- `dark(pts)`：最深色（乌鸦、瞳孔、笔芯）→ 所有版都涂满，叠出近黑。三色全叠时，深色边上会因错位露出彩边，这是对的。
- 想要混色（蓝叠黄的绿草、粉叠金的珊瑚小草）就别挖，两版都涂。
- 浅色：同一版涂低浓度（0.16–0.35）。
- 印的顺序：两种点缀色先印，满版底色最后印。

## 风格标尺（参数手感）

**错位要小。** 真实 Riso 偏零点几到一毫米。600–900 宽的画：各版 `offset` 2–3px，`rot` 0.05–0.15 度。故意错开的字（粉字 + 金字）只错 3–4px，大约笔画宽的三分之一。错 10px 以上就成了「立体字特效」，不像印歪。错位要小到让人觉得「诶好像没对准」，不是一眼看出故意。

**挖空 + 错位 = 白缝。** 这是最像真的效果：底色版挖掉月亮/字的位置，另一版印月亮/字，两版各偏一点，一侧露出一条白纸缝，另一侧两色叠暗。不用额外做，按分版写就自然出来。

**浅色用细网点，不用颗粒。** 颗粒网在低浓度 = 白纸上随机撒点 = 像灰尘、很脏。浅色、阴影、毛卷都用 `screen="dots", cell=4.0–4.5`，整整齐齐像色卡。满版实地两种都一样（浓度 1 直接实心）。
**不完美只放在该放的地方**：错位、墨不匀、擦痕可以有；形状和网点本身要干净。

**阴影不要渐变，用一块干净的月牙**：同色低浓度画整块，再用偏移过的同形状挖掉，剩一弯。

**实地的绒面**：`velvet=0.35–0.4`（满版底色），点缀色 0.25。超过 0.6 像下雪。
**擦痕** `scuffs=2–4` 只给底色版。**滚筒条纹** `streak=0.04`。
**轮印**（滚轮蹭到湿墨再压回别处）：`roller_ghost(paper, 底色版, shift=-300~-470, alpha=0.05–0.06)`，只在纸色区域看得出。
**金属金**：`gold` 油墨 + `sparkle=0.0006`。
**网点角度**：三版分别 15° / 75° / 45°，避免撞网。

## 油墨（近似 sRGB）和好用的组合

`fluo_pink` (255,72,176) · `yellow` (255,232,0) · `blue` (0,120,191) · `bright_blue` (0,94,200) · `medium_blue` (50,85,164) · `teal` (0,131,138) · `green` (0,169,92) · `red` (255,102,94) · `orange` (255,108,47) · `sunflower` (255,181,17) · `aqua` (94,200,229) · `gold` (178,148,98) · `black`

验证过的三色组：
- 蓝 + 荧光粉 + 黄：天空/白天。乌鸦（三叠）近黑带墨绿。
- 亮蓝 + 荧光粉 + 金：夜空，最「Riso」。
- 荧光粉 + 蓝绿 + 黄：甜、糖果感。
- 红 + 黄 + 中蓝：零食、热闹。乌鸦偏深褐。
- 藏青(medium_blue) + 黄 + 荧光粉：夜晚；蓝叠黄 = 草绿。
- 黄（满版）+ 荧光粉 + 中蓝：封面、标题大字。

注意：两色都是 100% 叠时混色会发闷，想要亮的混色让其中一版浓度 0.5–0.7。

## 角色画法

**乌鸦怎么画才像乌鸦**（不像鸭子）：
- 站着，身体斜挺（椭圆转 0.5 弧度，胸口朝左上），不要趴平。
- **头顶平**，额头和嘴几乎一条斜线 → 侧脸「凶萌」。
- **嘴又粗又厚**，尖端微微往下勾。细直的嘴 = 鸭子。
- 尾巴楔形，两条细腿，眼睛是挖白的小圆 + 深色瞳孔。
- 飞的时候翅膀用一个转过的长椭圆 + 三根椭圆羽尖，别用直边多边形（会像一面黑旗子）。
- 颜色用 `dark()` 三版全叠。
- 现成函数：`example.py` / `example_cards.py` 里的 `crow_stand()`、`crow_fly()`。

**毛团 / 云 / 棉花糖 / 爆米花**：都是 `scallop()`。毛团 bumps 20–26、depth 0.09–0.12；云 bumps 9–11、depth 0.26；爆米花 bumps 6、depth 0.28。整块 knock 成纸色，加一弯淡月牙阴影 + 十几个细网点小卷（小卷避开脸）。

**小羊脸**（`sheep_face()`）：一个竖椭圆脸 + 两只横椭圆耳朵（`solid` 一个颜色），两个挖白大圆眼 + `dark` 瞳孔，嘴是挖白的一道小弧；脸上方挖几团纸色当刘海，脸就「长」在毛团里。

## 工作流

1. 一句话写下点子，以及画里的东西各对应哪件真事。
2. 选三色（上面的组合起手）。定底色。
3. 拷 `example.py` 改，别从空白起：先 `frame()` 铺底色 → 大形（knock 的纸色块）→ 角色 → 细节挖白 → 字。坐标全写成变量。
4. `c.print()` 出图，再用 `R.preview_plates([...])` 看每张版单独长什么样，检查分色对不对。
5. 看五样：有没有点子；底色铺满了没；错位是不是小到刚好；浅色是不是干净网点；有没有东西伸出边框、压住小字。两版内。
6. 输出 `riso-<主题>-<日期>.png`，脚本留同目录。系列作品顺手拼一张合集图（`example_cards.py` 末尾有）。

## 反馈怎么读

- 「有点脏」= 浅色用了颗粒网 → 换细网点；或 velvet 太高。
- 「错位太大」= offset 超过 3px 或文字错开超过 4px。
- 「不像 XX」= 剪影特征不对，先找最有辨识度的两个形（乌鸦：平头 + 粗嘴）。
- 「不知道 Riso 该是什么样」= 让对方找几张参考，只学颜色、颗粒、错位，一根线都不照描。

## 坑

- knock 是乘法挖空，挖完再 `poly(..., mode="max")` 才能补回来；想覆盖成新浓度用 `mode="set"`。
- 字要先在临时 Plate 上画，再从其他版挖掉，否则底色压住字（`text_ink` / `text_knock` 已经这么做）。
- 角色的尾巴/翅膀容易伸出边框印到白边上——检查最右最下的点。
- 小字放底部白边上方时，别让掉落的爆米花、草地压住。
- 随机种子固定（`R.setup(..., seed=)`），改参数才能对比。
- `setup()` 会改全局尺寸；一个脚本画多张时，每张开头都要重新 `setup()`。

## 引擎函数表（`import riso_lib as R`）

| 函数 | 干什么 | 手感 |
| --- | --- | --- |
| `setup(w, h, ss=2, seed)` | 定尺寸、超采样、种子 | 每张画开头调一次 |
| `Plate(ink)` | 一张版；`ink` 填 `INKS` 里的名字或 RGB | `.d` 是浓度图，可以直接 numpy 运算 |
| `.poly(pts, density, mode)` | 多边形 | mode：`max` 叠加 / `set` 覆盖 / `knock` 挖掉 |
| `.line(pts, width, density, mode)` | 粗线（圆头） | 挖白细节用 `mode="knock"` |
| `.text(s, xy, size, font, rot, anchor)` | 字 | 大标题 `FONT_BOLD`，小字 `FONT_REG` |
| `.gradient / .radial` | 线性 / 径向渐变 | 留给太阳、地面；阴影别用 |
| `ellipse_pts / blob / scallop / wobble_line` | 几何 | `scallop` 是毛团、云、爆米花 |
| `new_paper()` | 米白纸 + 细噪 | |
| `print_plate(paper, plate, screen, cell, angle, offset, rot, velvet, scuffs, sparkle, ...)` | 把一版印上去 | 见「风格标尺」 |
| `roller_ghost(paper, plate, shift, alpha)` | 轮印 | alpha 0.05–0.06 |
| `finish(paper, path)` | 缩回原尺寸存图 | |
| `preview_plates(plates, path)` | 每版单独印一排 | 检查分色 |
